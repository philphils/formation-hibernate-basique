# 🚀 Formation Hibernate - Concepts de Base

## 📌 Description
Cette formation couvre les **concepts fondamentaux** du framework **Hibernate** en Java. Elle inclut des **exemples pratiques** et un **projet de TP** pour mettre en application les notions abordées. Les TP sont inspirés des principes de développement en TDD (Test Driven Development)

## 🏗️ Contenu de la formation :
- 🔹 **Mapping des objets** avec Hibernate
- 🔹 **Opérations CRUD** (Create, Read, Update, Delete)
- 🔹 **Mapping des héritages** (Single Table, Joined Table…)
- 🔹 **Gestion des associations** (OneToOne, OneToMany…)
- 🔹 **Lazy Loading & Fetching**
- 🔹 **Requêtes complexes** avec **JPQL & Criteria API**
- 🔹 **Configuration du framework** et bonnes pratiques

## 📂 Contenu du dépôt
- 📖 **Diaporama** explicatif 📑 (`Documentation/diapo_formation_hibernate.odp`)
- 💻 **Projet Java** contenant les exercices de TP 🛠️ (`formation-hibernate/`)
- 📄 **Documentation** et instructions 📚 (`Documentation/`)

## 🏁 Prérequis
- Connaissances de base en **Java**
- IDE comme **IntelliJ / Eclipse**
- **Maven** ou **Gradle** installé
